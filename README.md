# とりメモ

撮って、まとめて、書く。
写真・動画・音声・書類・メモを、案件ごとのフォルダにまとめて残すためのアプリです。

**開く → https://yuudagawa-sys.github.io/torimemo/**

iPhone は Safari で開いて、共有ボタン →「ホーム画面に追加」。
Android は Chrome のメニュー →「アプリをインストール」。
一度入れれば、通信がなくても使えます。

## 仕組み

- 棚（ホーム）にフォルダが並び、上のタブ（カテゴリ）で絞り込めます
- フォルダの中に、写真・動画・録音・書類（PDF／文書／表／スライド）・メモが時系列で入ります
- タグと ★ で、あとから探せます
- フォルダごと ZIP で書き出して、別の端末に渡せます

## データの置き場所

すべて端末の中（IndexedDB）だけに保存されます。
サーバーには何も送りません。書き出した ZIP を渡す以外に、外へ出る経路はありません。

## 中身

| ファイル | 役目 |
|---|---|
| `index.html` | 画面の骨組みとアイコン |
| `style.css` | 見た目。配色12色ぶんの定義を含む |
| `app.js` | 全部の動き。保存・書き出し・カメラ・録音 |
| `sw.js` | 通信がなくても開けるようにする |
| `manifest.webmanifest` | ホーム画面に置くときの名前とアイコン |
