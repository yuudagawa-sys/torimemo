# フォルポ（Folpo）

出来事ごとにフォルダを作って、その場で撮った写真・動画・録音・書類・メモを放り込んでおくアプリです。
展示会・取材・ロケハン・会議・旅行に。

**開く → https://yuudagawa-sys.github.io/torimemo/**

- iPhone：Safari で開いて、共有ボタン →「ホーム画面に追加」
- Mac・パソコン：Chrome で開いて、アドレスバーの右の「インストール」

## データの置き場所

写真・動画・録音・メモは、**その端末の中**に保存されます。フォルポのサーバーに送られることはありません。
機種変更の前には、設定の「まるごとバックアップ」で書き出してください。

くわしくは [プライバシーポリシー](privacy.html)。

## このリポジトリについて

配信用の写しです。中身は HTML・CSS・JavaScript だけで、ビルドは要りません。
開発の本体（仕様・計画・テスト）は、持ち主の非公開リポジトリにあります。
秘密情報（API キー・証明書など）は入っていません。`app.js` にある Google のクライアント ID は、公開して使う前提の番号です。
